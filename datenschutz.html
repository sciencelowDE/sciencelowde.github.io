Was die Anwendung tut

„ScienceLow Upload“ ist ein internes Werkzeug. Es lädt eigene Videos, Vorschaubilder und Untertitel über die YouTube Data API auf den eigenen YouTube-Kanal von ScienceLow hoch. Die Anwendung wird nur vom Kanalbetreiber für das eigene Konto genutzt.

Welche Daten verarbeitet werden

  • Ein OAuth-Zugangstoken für das eigene YouTube-Konto. Es wird verschlüsselt als Geheimnis in der Ausführungsumgebung (GitHub Actions) gespeichert und an niemanden weitergegeben.
  • Die hochgeladenen eigenen Inhalte (Video, Titel, Beschreibung, Vorschaubild, Untertitel) und die zurückgegebene Video-ID.

Es werden keine Daten anderer Nutzer abgerufen, gespeichert, verkauft oder für Werbung verwendet.

YouTube und Google

Die Anwendung nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
