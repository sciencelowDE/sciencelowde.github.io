Nutzungsbedingungen – ScienceLow Upload

„ScienceLow Upload“ ist ein internes Werkzeug des Kanals ScienceLow. Es wird ausschließlich vom Kanalbetreiber genutzt, um eigene Videos auf den eigenen YouTube-Kanal hochzuladen. Es gibt keine externen Nutzer und keinen öffentlichen Zugang.

YouTube API Services

Die Anwendung nutzt die YouTube API Services. Mit der Nutzung gelten die Nutzungsbedingungen von YouTube sowie die Datenschutzerklärung von Google. Hochgeladen werden nur eigene, selbst erstellte Inhalte, die den YouTube-Community-Richtlinien entsprechen.

Daten

Welche Daten verarbeitet werden, steht in der Datenschutzerklärung. Der Zugriff der Anwendung auf das YouTube-Konto kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
